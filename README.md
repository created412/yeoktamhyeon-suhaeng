# 역탐현 수행평가 제출

학생은 GitHub Pages의 웹 양식으로 제출하고, 제출 내용은 선생님의 구글 시트와 구글 드라이브에 저장된다.

| 파일 | 용도 |
|---|---|
| `index.html` | 학생용 첫 화면(수행평가 1~4 목록) |
| `suhaeng1.html` | 수행평가 1 제출 양식(워크북 1 빈칸 + AI 사용 기록 + AI 공유 링크 + 한글 파일 첨부(선택)) |
| `teacher.html` | 교사용 열람(반별 필터, 검색, 학생별 본문 복사, CSV) |
| `apps-script/Code.gs` | 구글 시트에 붙일 서버 코드 |
| `config.js` | Apps Script 웹 앱 URL을 넣는 곳 |

## 최초 1회 설정 (약 5분)

1. 구글 드라이브에서 **새 스프레드시트**를 만든다 (예: `역탐현 수행평가 제출`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 `Code.gs`의 내용을 모두 지우고, `apps-script/Code.gs`의 내용을 붙여 넣는다.
4. 맨 위 `TEACHER_KEY`를 원하는 비밀번호로 바꾸고 저장한다.
5. 함수 목록에서 `authorize`를 골라 **실행**한다. 권한 승인 창에서 본인 계정을 허용한다.
   (「확인되지 않은 앱」이 뜨면 **고급 → (프로젝트 이름)(으)로 이동**)
6. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
7. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해
   `config.js`의 `SCRIPT_URL` 따옴표 안에 붙여 넣고 커밋·푸시한다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영된다(URL은 그대로 유지).

## 저장 방식

- 시트 탭 `수행1`~`수행4`: 학번당 한 줄. 다시 제출하면 **마지막 제출본으로 갱신**되고 `최초 제출`·`제출 횟수`가 남는다.
- 시트 탭 `제출기록`: 모든 제출을 원본 그대로 쌓는다(덮어쓰지 않음).
- 첨부 파일: 내 드라이브 `역탐현 수행평가 첨부/수행N/` 폴더. 파일명 `수행1_학번_이름_날짜.hwp`.
- 학번은 5자리(예: 20315 → 3반 15번)로 받아 `반`·`번호`를 자동으로 나눈다.

## 수행평가 2~4 추가

`suhaeng1.html`을 복사해 `suhaeng2.html`로 만들고, 칸 내용과 `task: "수행2"`, `collect()`의 항목만 바꾼다.
`index.html`에서 해당 카드를 링크로 바꾼다. 서버 코드는 고칠 필요 없다(새 탭·새 열이 자동으로 생긴다).
